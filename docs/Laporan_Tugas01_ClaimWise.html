1. BUSINESS PROBLEM FRAMING & KARAKTERISTIK BISNIS

1.1 Profil Organisasi Enterprise

PT Asuransi Sehat Sejahtera Tbk (HealthCare Shield Enterprise) merupakan perusahaan asuransi kesehatan swasta berskala nasional dengan lebih dari 3,5 juta pemegang polis aktif dan kemitraan dengan 1.800+ rumah sakit/klinik di Indonesia. Perusahaan mengelola rata-rata 45.000 klaim per bulan dengan perputaran dana klaim mencapai Rp 180 Miliar per kuartal.

1.2 Analisis Pain Points Bisnis Kuantitatif

  1. Bottleneck Triase Manual & Pelanggaran SLA: Seluruh klaim dialirkan melalui tahapan manual berjenjang yang sama, menyebabkan rata-rata waktu penyelesaian klaim membengkak hingga 16,8 hari kerja, melanggar ketentuan OJK (POJK No. 69/POJK.05/2016 maksimal 14 hari).
  2. Tingginya Biaya Operasional Penanganan Klaim (Handling Cost): Pelibatan dokter spesialis dan investigator pada seluruh klaim tanpa stratifikasi risiko menelan rata-rata Rp 145.000 per klaim (8,2% dari total beban operasional tahunan).
  3. Kebocoran Fraud (Fraud Leakage) & False Rejection: Beban kognitif verifikator yang mencapai 60–80 berkas/hari memicu kelelahan dan membuka celah klaim fiktif/ganda, dengan estimasi kebocoran klaim fraud mencapai 7,4% (Rp 13,3 Miliar/tahun).

1.3 Justifikasi Pemilihan Solusi AI

Penyelesaian masalah triase manual tidak efektif menggunakan rule-engine statis karena variabilitas medis yang kompleks. Pendekatan State-Space Search (UCS & A*) memungkinkan optimasi alur keputusan berdasarkan bobot biaya riil (biaya tenaga kerja + waktu SLA). Solusi ini menjadi fondasi bagi arsitektur Copilot 5-Lapis (OCR, ChromaDB RAG, ReAct Agent Gemini 2.5 Flash, dan Gradio).

2.2 Analisis 7 Karakteristik Lingkungan Operasional (Russell & Norvig)

  1. Partially Observable: Agen tidak memiliki visibilitas lengkap atas niat nasabah atau rekam medis masa lalu yang tidak dilampirkan; persepsi terbatas pada payload berkas klaim dan basis data internal.
  2. Multi-Agent: Bersifat kooperatif terhadap nasabah sah dan dokter mitra; bersifat adversarial terhadap pelaku fraud asuransi.
  3. Stochastic (Bisnis) / Deterministic (State Space): Proses klaim riil mengandung ketidakpastian (stokastik), namun pemodelan alur verifikasi diabstraksikan menjadi fungsi transisi graf deterministik terkontrol.
  4. Sequential: Keputusan perutean di tahap awal (DocCheck, PolicyValidation) secara langsung memengaruhi state berikutnya dan akumulasi total biaya.
  5. Dynamic: Plafon polis nasabah, ketersediaan dokter verifikator, dan antrean klaim berubah terus-menerus selama agen beroperasi.
  6. Discrete: Status checkpoint, aksi routing, dan metrik biaya bernilai diskret terhitung.
  7. Known: Ketentuan SOP klaim, syarat klausul polis, dan formula biaya operasional telah diketahui dan terdefinisi dengan pasti.

3. FORMULASI FORMAL RUANG KEADAAN (X, A, T, G, C) & GRAF MASALAH

  • State Space (X): {Submitted, DocCheck, PolicyValidation, RiskScoring, FastTrack, StandardReview, MedicalReview, ApprovalOfficer, FraudInvestigation, Disbursement, Rejected}
  • Action Space (A): Transisi routing keputusan ke checkpoint penerus yang valid.
  • Transition Model (T): Fungsi deterministik berarah T(s, a) → s'.
  • Goal Test (G): State terminasi s ∈ {Disbursement, Rejected}.
  • Path Cost Function (C): c(s, s') = (Biaya_Staf_IDR / 50.000) + (Estimasi_SLA_Hari × 0.5) ≥ 1.0 > 0.

4. IMPLEMENTASI ALGORITMA SEARCH & PEMBUKTIAN MATEMATIS HEURISTIK

4.1 Sifat Heuristik untuk A* Search

Fungsi heuristik h(n) dirancang sebagai estimasi optimistik batas bawah biaya tersisa menuju goal terdekat:

HEURISTIC = {
    "Submitted": 7.0, "DocCheck": 6.0, "PolicyValidation": 5.0,
    "RiskScoring": 3.0, "FastTrack": 1.0, "StandardReview": 3.0,
    "MedicalReview": 3.0, "ApprovalOfficer": 1.0, "FraudInvestigation": 1.0,
    "Disbursement": 0.0, "Rejected": 0.0
}

Pembuktian Matematis:

1. Admisibilitas (h(n) ≤ h*(n)):
Biaya riil optimal dari masing-masing node ke goal: h*(Submitted)=9.0 ≥ 7.0; h*(DocCheck)=8.0 ≥ 6.0; h*(PolicyValidation)=6.0 ≥ 5.0; h*(RiskScoring)=4.0 ≥ 3.0; h*(FastTrack)=1.0 ≥ 1.0; h*(StandardReview)=8.0 ≥ 3.0; h*(MedicalReview)=4.0 ≥ 3.0; h*(ApprovalOfficer)=1.0 ≥ 1.0; h*(FraudInvestigation)=2.0 ≥ 1.0; h*(Disbursement)=0.0; h*(Rejected)=0.0.
Kesimpulan: Seluruh state memenuhi 0 ≤ h(n) ≤ h*(n), sehingga terbukti Admissible.

2. Konsistensi / Monotonisitas (h(n) ≤ c(n, n') + h(n')):
Untuk setiap edge (n, n') dengan bobot c(n, n'), pertidaksamaan segitiga terpenuhi sempurna. Contoh:
• Submitted → DocCheck: 7.0 ≤ 1.0 + 6.0 = 7.0 (Terpenuhi)
• DocCheck → PolicyValidation: 6.0 ≤ 2.0 + 5.0 = 7.0 (Terpenuhi)
• RiskScoring → FastTrack: 3.0 ≤ 3.0 + 1.0 = 4.0 (Terpenuhi)
Kesimpulan: Heuristik terbukti Consistent, menjamin tidak ada simpul yang di-reopen pada Graph Search.
